# 🔢 Bin2Dec - Conversor de Binário para Decimal

Uma aplicação simples em Node.js desenvolvida para converter números binários de até 8 dígitos (compostos apenas por `0` e `1`) em seus equivalentes decimais.

O projeto utiliza o módulo nativo `readline` do Node.js para interagir diretamente com o usuário através do terminal.

---

## 🚀 Funcionalidades

*   **Validação de Entrada:** Garante que o usuário digite apenas números binários (`0` e `1`).
*   **Limite de Caracteres:** Aceita entradas de até 8 dígitos binários.
*   **Conversão Instantânea:** Transforma o valor binário em decimal e exibe o resultado no terminal.
*   **Interface via CLI:** Interatividade simples sem a necessidade de dependências externas.

---
